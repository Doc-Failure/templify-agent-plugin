# DOCX cover design

Use this pattern for the opening page of a DOCX proposal, report, brief, or plan. It is a composition reference, not a fixed visual theme.

## Composition

- Use one dedicated full page before the body.
- Create a strong visual field using the brief's brand colors: a solid fill, gradient, geometric shapes, or a carefully packaged image.
- Place the main title in a high-contrast block, with a clear typographic hierarchy and comfortable wrapping for long titles.
- Add a short subtitle or value statement below the title.
- Use one restrained accent rule, shape, or color detail to anchor the title block.
- Place metadata toward the lower portion of the page: prepared for, prepared by, date, and an optional document status or validity line.
- Keep the cover intentionally sparse. Do not put body sections, tables, pricing details, or dense copy on it.

## Portability

- Prefer embedded shapes, SVGs, and images over remote assets.
- Use fonts available in the target environment or package a safe fallback; never rely on a web font URL at render time.
- Maintain readable contrast and test long client names, long titles, and missing optional metadata.
- Keep logos and decorative artwork within the page bounds and preserve their aspect ratio.
- Use an explicit page or section break so the first body section always starts on page two.

## Brand adaptation

The cover may be inspired by a reference such as a dark editorial cover with an accent rule and bottom metadata, but its colors, typography, spacing, imagery, and wording must come from the current brief and brand evidence. Do not reproduce a reference template's proprietary branding or client information.
